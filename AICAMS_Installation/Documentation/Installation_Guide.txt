--------------------------------------------------------------------------------
1. HOST SERVER SETUP & DATABASE INITIALIZATION (ONCE PER LAB)
--------------------------------------------------------------------------------
Execute these configuration steps on the dedicated Instructor Host PC only:

A. SQL Server Network Configuration:
   1. Open "SQL Server Configuration Manager".
   2. Expand "SQL Server Network Configuration" -> "Protocols for SQLEXPRESS".
   3. Ensure "TCP/IP" is set to ENABLED.
   4. Double-click "TCP/IP", switch to the "IP Addresses" tab, scroll down to "IPAll":
      - Set "TCP Port" to: 1433
      - Clear any value in "TCP Dynamic Ports".
   5. Expand "SQL Server Services", right-click "SQL Server (SQLEXPRESS)", and restart it.
   6. Ensure the "SQL Server Browser" service is running and set to Automatic startup
      (required for client machines to resolve named instances over the network).

B. Windows Firewall Inbound Rules:
   Open PowerShell as Administrator on the Host PC and run:
   New-NetFirewallRule -DisplayName "SQL Server (TCP 1433)" -Direction Inbound -Protocol TCP -LocalPort 1433 -Action Allow
   New-NetFirewallRule -DisplayName "SQL Browser (UDP 1434)" -Direction Inbound -Protocol UDP -LocalPort 1434 -Action Allow

C. Database Seeding:
   1. Open PowerShell or Command Prompt on the Host PC.
   2. Run the idempotent seed script targeting the local SQL instance:
      sqlcmd -S ".\SQLEXPRESS" -d aicams -i "Database_Backups\aicams_seed_data.sql"
   3. Verify database population:
      sqlcmd -S ".\SQLEXPRESS" -d aicams -Q "SELECT COUNT(*) AS StudentCount FROM dbo.students;"
      (Expected: >= 4 records)

2. CLIENT WORKSTATION DEPLOYMENT
--------------------------------------------------------------------------------
Deploy the client software on each student laboratory workstation:

A. Install the Application:
   1. Copy "AICAMS_Setup.exe" to the workstation or run it from a shared network drive.
   2. Right-click "AICAMS_Setup.exe" and select "Run as administrator".
   3. Follow the wizard. The installer automatically checks for the Microsoft Visual C++
      2015-2022 x64 Redistributable and silently installs it if missing.
   4. The application is installed to "C:\Program Files\AI-CAMS" with a desktop shortcut.

B. First-Time Setup Wizard (Interactive Configuration):
   When launching AI-CAMS for the first time (or if the database connection fails),
   the interactive Setup Wizard launches automatically:

   Step 1: Database & Workstation Role
     - Workstation Role: Select "Student Workstation (Client)"
     - SQL Server Host: Enter "<HOST_PC_OR_IP>\SQLEXPRESS" (e.g., "192.168.1.100\SQLEXPRESS")
     - Database Name: "aicams" (or "aicamsdb")
     - Authentication: Select "Windows Authentication" (if on domain) or "SQL Server Authentication"
     - Certificate: Ensure "Trust Server Certificate" is checked
     - Diagnostics: Click "Test Connection"
       * A green badge displays table count upon successful verification.
       * If connection fails, actionable hints (Firewall 1433, TCP/IP, or credentials) are displayed.
     - Click "Next: Review Policies ->"

   Step 2: Operational Policies & Academic Compliance Agreement
     - Review the three mandatory institutional policies:
       1. Vision Monitoring & Privacy Safeguards (face detection, gaze tracking, presence logging;
          no continuous video saved to cloud; metrics and anomaly snapshots stored locally).
       2. Kiosk-Mode Lockdown & OS Controls (task-switching suppression like Alt+Tab, Alt+F4, WinKey;
          clipboard restrictions; low-level keyboard hooks authorization).
       3. Local Network & AI Data Transmission (all records remain on local host DB; outbound internet
          used strictly for encrypted AI evaluation assistance; instructor retains final grade authority).
     - Check all three compliance check boxes (or click "Toggle / Accept All").
     - Click "Save & Launch AI-CAMS".

C. Manual Reconfiguration Anytime:
   To change the host address or review policies after initial setup, click the
   "Database Setup" gear button located at the top-right corner of the login screen.

5. TROUBLESHOOTING
--------------------------------------------------------------------------------
- Issue: Setup Wizard reports "Cannot connect to server <HOST_PC_OR_IP>\SQLEXPRESS".
  Resolution:
    a. On Host PC: Ensure SQL Server (SQLEXPRESS) and SQL Server Browser are Running.
    b. On Host PC: Confirm inbound firewall ports TCP 1433 and UDP 1434 are allowed.
    c. On Client: In PowerShell, test network reachability:
       Test-NetConnection -ComputerName "<HOST_PC_OR_IP>" -Port 1433
       If "TcpTestSucceeded" is False, check physical Ethernet cables and subnet routing.

- Issue: Camera feed is black or reports an initialization error.
  Resolution:
    a. Check Windows Camera Privacy Settings ("Settings" -> "Privacy & Security" -> "Camera").
    b. Ensure "Let desktop apps access your camera" is toggled ON.
    c. Ensure no third-party background applications (Zoom, Teams, Chrome) have exclusive webcam locks.

- Issue: Application crashes immediately on launch.
  Resolution:
    Re-run "VC_redist.x64.exe" from the "Prerequisites" folder and choose "Repair" to
    ensure MSVCP140.dll and VCRUNTIME140.dll are properly registered.
