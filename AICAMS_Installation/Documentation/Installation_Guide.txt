5. TROUBLESHOOTING
--------------------------------------------------------------------------------
- Issue: "Cannot connect to server DESKTOP-QD67JHP\SQLEXPRESS" on client machines.
  Solution:
    a. On Host Server (DESKTOP-QD67JHP):
       - Ensure SQL Server (SQLEXPRESS) and SQL Server Browser services are running.
       - In SQL Server Configuration Manager, ensure TCP/IP is Enabled under SQL Server Network Configuration.
       - Ensure Windows Firewall allows inbound TCP traffic on port 1433 and UDP 1434.
    b. On Client:
       - Run: Test-NetConnection -ComputerName DESKTOP-QD67JHP -Port 1433

- Issue: Camera feed is black or shows an error.
  Solution: Check Windows Camera Privacy Settings ("Allow apps to access your
  camera"). Ensure no other application (e.g. Zoom, Teams, Chrome) is using the webcam.

- Issue: App crashes immediately on launch.
  Solution: Re-run "Prerequisites\VC_redist.x64.exe" and choose "Repair".
